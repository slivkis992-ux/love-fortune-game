# Любовная фортуна: игра для двоих

Вы с Аней открываете один адрес, нажимаете «Крутить колесо», и у обоих одновременно крутится колесо, появляется история про вас и картинка, где вы в этой сцене. ИИ работает через Cloudflare Workers AI.

## Структура репозитория

```
love-fortune/
├── server.js                  сервер: комната на WebSocket, ИИ
├── package.json               зависимости и команды запуска
├── .gitignore                 что не попадает в GitHub (.env, картинки)
├── .env.example               образец настроек (сам .env на GitHub не кладём)
├── photos/
│   ├── put-photos-here.txt
│   ├── dima.jpg               ваше фото (названия строго такие)
│   └── anya.jpg
└── public/
    └── index.html             страница игры (generated/ создаётся сама)
```

## 1. Ключи Cloudflare

1. Зарегистрируйтесь на dash.cloudflare.com (почты достаточно).
2. **Account ID** виден справа на главной странице аккаунта.
3. **API-токен**: My Profile → API Tokens → Create Token → шаблон **Workers AI** → Create. Скопируйте токен сразу, потом он не покажется.

Никому не отправляйте токен и не кладите его на GitHub.

## 2. GitHub

1. Создайте **приватный** репозиторий `love-fortune` (там будут ваши фото).
2. Add file → Create new file. В поле имени пишите путь целиком: `server.js`, `package.json`, `.gitignore`, `public/index.html`, `photos/put-photos-here.txt`. Слеш сам создаёт папку.
3. Фото: откройте папку `photos` → Add file → Upload files → перетащите `dima.jpg` и `anya.jpg`.
4. Не загружайте ZIP-архив (GitHub его не распакует) и не создавайте `.env`.

## 3. Render

1. render.com → Sign in with GitHub → New + → **Web Service** → репозиторий `love-fortune`.
2. Настройки:

| Поле | Значение |
| --- | --- |
| Runtime | Node |
| Build Command | `npm install` |
| Start Command | `npm start` |
| Instance Type | Free |

3. Environment → добавьте переменные:

| Key | Value |
| --- | --- |
| `CF_ACCOUNT_ID` | ваш Account ID |
| `CF_API_TOKEN` | ваш токен Workers AI |
| `ROOM_CODE` | `dima-anya` (или своё секретное слово) |

4. Create Web Service. Через несколько минут появится адрес вида `https://love-fortune.onrender.com`.

## 4. Играть вдвоём

Откройте `https://ВАШ-АДРЕС.onrender.com/?code=dima-anya`, нажмите «Пригласить Аню» и отправьте ссылку. Когда подключитесь оба, появится «Вы вдвоём 💘». Колесо крутит сервер, поэтому результат у вас одинаковый.

## Запуск у себя (необязательно)

Нужен Node.js 20.6 или новее. В папке проекта:

```
npm install
```

Скопируйте `.env.example` в `.env`, впишите ключи и запустите:

```
npm run dev
```

Адрес: `http://localhost:3000/?code=dima-anya`.

## Фото и лица

Картинки делает модель FLUX.2 klein: она получает ваши фото как образцы и рисует вас в сцене. Сходство бывает неидеальным, это нормально для такой модели. Лучше работают фото, где лицо крупно, хороший ровный свет, без очков и фильтров. Фото уходят в Cloudflare для генерации, поэтому берите только те, которыми вы оба готовы делиться.

Если фото нет или модель отказалась работать с ними, игра не ломается: картинка рисуется без ваших лиц (моделью FLUX.1 schnell), а на экране появляется пояснение.

## Лимиты и что знать

- Бесплатный лимит Cloudflare считается в сутки на весь аккаунт. Когда он кончится, история ещё может писаться, но картинки перестанут рисоваться до следующих суток. Расход смотрите в панели Cloudflare (AI → Workers AI).
- Хотите больше раундов за день: поставьте в Render `STORY_MODEL=@cf/meta/llama-3.1-8b-instruct`. Она дешевле, но по-русски пишет хуже.
- `IMAGE_SIZE` (по умолчанию 768) можно уменьшить до 512: картинка проще, но дешевле.
- Бесплатный Render засыпает после простоя. Первый вход после паузы грузится до минуты.
- История хранится в памяти сервера. После перезапуска она сбросится, поэтому в конце нажимайте «Скопировать всю историю».
- Сохранённые картинки лежат во временной папке `public/generated`. Нравится кадр, скачивайте кнопкой «Сохранить картинку».

## Если что-то не работает

- «Неверный код»: откройте ссылку с `?code=` и тем же значением, что в `ROOM_CODE`.
- «Фортуна не смогла написать историю»: проверьте `CF_ACCOUNT_ID` и `CF_API_TOKEN` в Render → Environment (без пробелов и кавычек) или не закончился ли дневной лимит. Подробности в разделе Logs.
- Картинка без лиц: смотрите в Logs, там будет причина. Иногда модерация Cloudflare отклоняет фото (код 3030), тогда попробуйте другие.
- Деплой упал с ошибкой про `sharp`: нажмите Manual Deploy → Clear build cache & deploy.
